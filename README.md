# 打造你的專屬 AI 秘書：配套素材

書本《打造你的專屬 AI 秘書：零基礎也能上手的 Claude Code 自動化實戰》（博碩文化 2026）的配套資源。

## 內容

- **`測試素材/`**：書中各章 demo 用到的素材（PDF、Excel、音檔、照片等）
- 後續會陸續加入 prompt 範本、Skill 檔案、範例程式碼

## 怎麼用

1. 整個 repo 點右上角 **Code** → **Download ZIP**，或 `git clone` 下來
2. 把 `測試素材/` 資料夾整個拖進 `~/AISpace/`
3. 翻書，章節提到「讓秘書整理 ch02_downloads」這類指引時，秘書就找得到對應素材
