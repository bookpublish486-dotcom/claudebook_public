# 打造你的專屬 AI 助理：配套素材

書本《打造你的專屬 AI 助理：零基礎也能上手的 Claude Code 自動化實戰》（博碩文化 2026）的配套資源。

作者：Ahzoon

配套 GitHub：<https://github.com/bookpublish486-dotcom/claudebook_public>

## 內容

- **`測試素材/`**：書中各章實作會用到的素材（PDF、Excel、音檔、照片等）。
- **`prompts/`**：按章節整理的 Prompt 範本，可以直接複製貼到 Claude Code 使用。

## 怎麼下載

1. 在這個 GitHub 頁面點綠色的 **Code** 按鈕，選 **Download ZIP**。
2. 解壓縮下載的 ZIP 檔，打開解壓縮後的資料夾。
3. 把裡面的 `測試素材` 資料夾整個拖進前面建立的 `AISpace` 工作資料夾。
4. 在 Claude Desktop 的 Code 分頁選擇 `AISpace` 作為工作資料夾，就可以跟著書中步驟開始操作。

例如第二章用到的下載資料夾，放好後的位置會是 `AISpace/測試素材/ch02_downloads`。

`prompts` 資料夾裡的範本可以按章節查看，需要時再複製到對話框裡。
