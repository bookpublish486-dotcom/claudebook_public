## Prompt 13 — Claude Code

```
建立新 skill /google。打 /google 時觸發，其他 skill 呼叫 Google API 也走這個 skill 拿 token。需求如下：

1. AISpace 裡有一個 credentials.json，是 Google OAuth 憑證
2. 第一次觸發時跑授權流程：開瀏覽器讓我登入、callback 拿到 token、把 token 存到 ~/AISpace/token.json
3. token 管理寫成 Python helper 腳本（用 google-auth 套件），每次呼叫前自動檢查 token、過期就刷新；要注意 token.json 裡的 expiry 是字串，用 datetime 比對前要記得轉 timezone-aware，否則 expired 判定永遠是 False、token 不會主動刷新
4. 呼叫 Google API 時用 token helper 拿 token，再用 curl 打 REST API（API 操作不用包 Python 函式，curl 即時組請求就好）
5. 例外：Gmail 發信時，Subject 若含中文要走 Python email 模組做 RFC 2047 MIME 編碼，不要用 curl 直接組 header，否則收信端會看到亂碼
6. OAuth scope 要對應前面啟用的 5 個 API：gmail.modify、drive、calendar、spreadsheets、documents
```

## Prompt 18 — Claude Code

```
建立新 skill /stock-sync，需求如下：

「股票交易紀錄」試算表已預先建好，分頁結構：
- 「交易紀錄」：日期 | 代號 | 名稱 | 買賣 | 股數 | 成交價 | 手續費 | 證交稅 | 淨額 | 來源
- 「持倉」：代號 | 名稱 | 持有股數 | 平均成本 | 總成本 | 現價 | 未實現損益
- 「已實現損益」：賣出日期 | 代號 | 名稱 | 賣出股數 | 賣出淨額 | 對應買進金額 | 損益金額
- 「同步狀態」：A1 儲存上次同步時間戳（YYYY/MM/DD HH:MM 格式），此分頁不設 header row

若找不到「股票交易紀錄」試算表，回報錯誤並提示「請先建立 Google Sheets 試算表再執行此 skill」，不要自動建立。

skill 邏輯：

1. 當我說「同步股票交易」或打 /stock-sync 時觸發
2. 從「同步狀態」分頁 A1 讀上次同步時間戳；若 A1 空，預設抓最近 30 天
3. 呼叫 google skill（OAuth + Gmail API）搜尋並下載附件，不要用 Gmail MCP（MCP 不能下載附件 bytes）。搜尋條件：主旨含「發大財證券」或「紅寶石證券」+ `after:` 上次時間戳的日期
4. 用 python-dotenv 從 `~/AISpace/.env` 載入 PDF 密碼（發大財用 `DAFACAI_PDF_PASSWORD`、紅寶石用 `HONGBAOSHI_PDF_PASSWORD`）
5. 解開附件 PDF，解析出：日期、代號、名稱、買賣別、股數、成交價、手續費、證交稅、淨額、券商名稱（券商寄的是電腦產生的數位 PDF，直接抽文字即可，不要走 OCR）。民國年自動轉西元年。淨額存入時一律取絕對值（買入為實際付出金額，賣出為實際收到金額）
6. 讀取「交易紀錄」分頁現有列，用「日期+代號+買賣別+股數」四欄當複合 key，缺一不可（同一天可能分批買進，股數必須納入）
7. 只寫入新交易，跳過已存在的
8. 寫入前列出待寫入清單讓我確認
9. 寫入新交易後，自動重新計算「持倉」「已實現損益」兩個分頁，統一用平均成本法（含買進手續費，每次賣出按比例扣減持倉成本）
10. 用 twstock 套件抓即時報價（`twstock.realtime.get('2330')` 取 `latest_trade_price`），更新「持倉」分頁的「現價」「未實現損益」欄
11. 寫入完更新「同步狀態」分頁 A1 為當前時間戳
12. 回報「新增 N 筆交易，跳過 M 筆已存在」
```
