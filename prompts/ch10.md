## Prompt 3 — skill-creator prompt

```
建立新 skill /image，產圖用 Pollinations。
所有設計決定都已經定好，**不要問我問題，照下面照做**。

== API 規格（請照這個，不要靠記憶或舊資料）==

- Host: https://gen.pollinations.ai
  ⚠️ 注意：不是 image.pollinations.ai，那個是 legacy 不認證的，
     會被強制降級成 sana 模型而且每張排隊 90 秒
- Endpoint: GET /image/{prompt}
- prompt 必須 URL encode
- 認證: Authorization: Bearer <token>，token 從環境變數讀
- 預設參數: model=flux, width=1024, height=1024
- 完整文件: https://enter.pollinations.ai/api/docs

== Token ==

- 變數名: POLLINATIONS_TOKEN
- 位置: ~/AISpace/.env
- 權限：.claudeignore 已經把 .env 擋掉，你不能 Read 它的內容。
  Skill 內部用 os.getenv('POLLINATIONS_TOKEN') 自己讀，
  全程不要 print、不要 echo、不要把 token 放進對話視窗

== Skill 行為 ==

trigger: 當使用者說「產圖」、「生成圖片」、「畫一張」、「image」、
「gen image」、打 /image 或任何要求用 AI 產生圖片的時候觸發

流程：
1. 從使用者的訊息抓出要畫的主題（中文或英文都可能）
2. 把主題翻成精準的英文 prompt
   - 加構圖、光線、風格、細節關鍵字
   - flux 對名詞、配件這類細節敏感，翻譯時要明確列出
   - 翻譯結果不用回報，內部用就好
3. 呼叫 gen.pollinations.ai 的 GET /image/{prompt}
   model=flux, width=1024, height=1024
   Authorization: Bearer $POLLINATIONS_TOKEN
4. 圖存到 ~/AISpace/images/
   檔名格式: YYYYMMDD_HHMMSS_<英文 prompt 前 20 字 slug>.jpg
   例: 20260410_143052_orange-cat-pink-bow-tie.jpg
   用 timestamp + slug 確保不會撞檔
5. 用系統預設圖片檢視器打開圖片
6. 回報檔名（不報內容、不報 token、不報翻譯後 prompt）

不要做的事：
- 不要自動串 notify Skill。要推手機由我在 prompt 外層自己加
- 當我說「發到 LINE」「推到 Telegram」時，用 notify Skill 發送，
  絕對不要用 computer-use 操作我的電腦上的 LINE/Telegram app
- 不要寫成 OpenAI SDK 相容的版本（POST /v1/...），用最簡單的 GET 就好
- 不要加 private、nologo 這類參數，官方 OpenAPI schema 沒有

== 額度提醒 ==

我的 key 是 Spore tier，每小時補 0.01 pollen。
flux 是 0.001 pollen/img，所以一小時上限大約 10 張。

如果撞到 HTTP 429（rate limit）或 402（餘額不足），
直接回報錯誤訊息，不要默默重試。

---

寫完之後幫我跑一次驗收：
「畫一張穿著太空衣的柴犬，站在月球上」
```

## Prompt 5 — skill-creator prompt

```
建立新 skill /bluesky，管理我的 Bluesky 帳號。
打 /bluesky 進入主入口；自然語言 trigger 見下方各功能。
所有設計決定都已經定好，不要問我問題，照下面做。

== 帳密 ==

- 變數名：BLUESKY_HANDLE、BLUESKY_APP_PASSWORD
- 從 .env 用 python-dotenv 讀，不要直接讀 .env 檔案
- 全程不要把帳密印出來或放進對話視窗

== 功能 ==

1. 發純文字貼文
   trigger：「發到 Bluesky」「Bluesky 發文」「po 到 bsky」
   用 atproto 的 client.send_post()

2. 發圖文貼文
   trigger：帶圖路徑 + 發文相關關鍵字
   用 client.send_image()，alt text 用圖片檔名

3. 按讚
   trigger：「給最新貼文按讚」或指定貼文 URI
   先用 client.get_author_feed() 拿最新貼文的 URI + CID，再 client.like()

== 完成後 ==

幫我發一則測試文：「Bluesky Skill 就緒 🤖」，發完回報貼文 URI。
```

## Prompt 8 — skill-creator prompt

```
建立新 skill /blogger，管理我的 Blogger 部落格「萬事通克勞黑的地理小知識」。
打 /blogger 進入主入口；自然語言 trigger 見下方各功能。
所有設計決定都已經定好，不要問我問題，照下面做。

== 認證 ==

- 認證用 Google OAuth，跟前面 Google 服務共用同一組憑證
- 全程不要把 token 或 client secret 印出來或放進對話視窗

== 功能 ==

1. 發想主題
   trigger：「想部落格主題」「blog 主題」
   根據使用者指定的方向，產出 10 個文章主題

2. 寫草稿
   trigger：「寫一篇部落格」「擴寫成文章」
   根據指定主題寫成約 1500 字的草稿
   如果有風格參考檔（~/AISpace/blog_style.md），照那個風格寫
   草稿先展示給使用者看，不要自動推上 Blogger

3. 發佈到 Blogger
   trigger：「發到 Blogger」「發佈到 Blogger」「推上部落格」
   把使用者確認過的稿子用 Blogger API v3 發佈，狀態設成已發佈
   發完回報文章標題和公開網址
   發送前要處理兩件 Blogger 的限制：
   - 草稿是 Markdown 的話先轉成 HTML 再送（Blogger API 不吃 Markdown）
   - 草稿裡的 local 圖片路徑（例：測試素材/xxx.png）
     先上傳 Google Drive 取公開網址，把 HTML 裡的 <img src> 換成公開 URL 再送
     Drive 直連偶爾會失效，備案用 Imgur 或 Catbox

== 部落格資訊 ==

- 部落格名稱：萬事通克勞黑的地理小知識
- 主題方向：地理小知識，語氣像跟朋友聊天，每個知識點附來源或出處

== 完成後 ==

幫我發一篇測試文，標題「Blogger Skill 測試」，
內容隨便寫一段，發完回報網址。
```
