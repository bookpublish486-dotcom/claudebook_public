## Prompt 1 — Claude Code

```
建立新 skill，需求如下：

1. 當我說「轉逐字稿」或打 /transcribe 時觸發
2. 來源音檔沒給就問我；輸出預設存到音檔同資料夾，檔名「原始檔名_逐字稿.txt」，不用問
3. 用 Groq Whisper API 把音檔轉成文字
4. Skill 內部用 python-dotenv 從 ~/AISpace/.env 載入 GROQ_API_KEY，不要 Read .env，也不要把 key 寫進 Skill 檔案或腳本
5. 如果音檔超過 25MB，先切成小段再分批上傳
6. 轉完之後把簡體轉成繁體中文，加上標點符號和段落分段
```
