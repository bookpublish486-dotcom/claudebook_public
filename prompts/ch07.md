## Prompt 1 — Claude Code

```
幫我建立一個 PDF 轉檔的 Skill，當我說「轉 PDF」或打 /pdf 時觸發，流程如下：

1. 來源沒給就問我；輸出預設放在來源旁的 md/ 子資料夾，不用問
2. 用 pymupdf4llm 把所有 PDF 轉成 markdown
3. 檢查轉出來的 markdown，如果是空白或幾乎沒有文字（掃描件），把每頁轉成圖片，用 Read 直接看圖片內容，整理成 markdown
4. 如果 PDF 裡有嵌入的圖片（表格截圖之類的），提取出來存到輸出資料夾的 pic/ 底下，用 Read 看圖片內容，把圖片裡的資訊補進 markdown，並保留圖片參照
5. 轉完列出每份 PDF 的結果（文字轉換/圖片辨識/失敗）

重要：以後任何需要讀 PDF 的任務，都先用這個 Skill 轉成 markdown 再讀，不要直接用 Read 讀 PDF
```
