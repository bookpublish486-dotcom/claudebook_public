## Prompt 1 — Claude Code

```
在目前資料夾建立 CLAUDE.md，內容如下：

# 工作規則

## 語言
- 永遠用繁體中文回覆
- 中英文之間加空格（例：用 Python 寫腳本）

## 回覆方式
- 先給結論，再給細節
- 不確定就列 A/B/C 給我選，不要自己決定
- 不要主動加建議，除非我問
- 長文用條列，不要寫成一大段

## 動作前確認
- 操作前先說你打算怎麼做，我同意再動手
- 刪除、覆蓋、寄信、上傳前先列清單讓我確認

## 絕對不可以
- **不要**讀取或修改密碼、金鑰相關的檔案
- **不要**自行安裝套件，先告訴我需要什麼、為什麼

## 個人習慣
- 報告稱「客戶」不要用「使用者」
- 用「文件」不要用「文檔」
- 日期格式：YYYY-MM-DD
```
